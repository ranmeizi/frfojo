# PaddleOCR browser models (PP-OCRv4 mobile)

Used by the in-page OCR (ppu-paddle-ocr + onnxruntime-web).

Regenerate / download:

```bash
node fetch-paddle-ocr-models.mjs
# or
node fetch-paddle-ocr-models.mjs --force
```

Files:

- `PP-OCRv4_mobile_det.onnx`
- `PP-OCRv4_mobile_rec.onnx`
- `ppocrv4_dict.txt`
